# Сюжет и объём

**СОГЛАСОВАНО.** 1996 год, небольшой промышленный город США. Иван — младший офицер полиции, эмигрировавший подростком из СССР с отцом и двумя братьями. Отец Фёдор и брат Алексей исследуют перемещения во времени в лаборатории под действующим предприятием.

Трое бандитов захватывают лабораторию. Система безопасности Фёдора запирает их с учёными и автоматически вызывает полицию. Фёдор настраивает установку для перемещения Ивана. Захватчики держат учёных живыми в надежде выбраться. Заложники находятся отдельно, план заблокированной зоны открыт.

У телефона Иван узнаёт адрес. Он уже знает об установке. Опасность для семьи он осознаёт позже. По уточнению от 22 ноября Алексей оставляет по записке в комнатах 2 и 3, Фёдор отвечает в комнате 4. Это сюжетные записки без подсказок. Записка за тиром отложена.

По уточнению автора от 23 ноября 2026 учёный Фёдор Карамазов тайно разработал пульт возвращения в СССР и увёз его с собой в США. Игрок узнаёт об этом при подборе пульта в [комнате 1](rooms/01-introduction.md).

Две локации — участок и лаборатория. В открытые комнаты можно возвращаться. Около 40 минут на полную игру — предварительный ориентир.
