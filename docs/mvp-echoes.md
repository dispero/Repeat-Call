# Текущий MVP — участок и первая комната

21 ноября 2026 по просьбе автора в сцену Editor подключена комната 3 с двумя копиями. В неё можно войти через правый выход комнаты 2. Согласованный объём MVP остаётся прежним.

Иван отвечает на автоматический вызов в [полицейском участке](rooms/00-police-station.md), отправляется в подвал и осваивает возврат с одной копией в [первой комнате](rooms/01-introduction.md). Пересечение правого прохода сохраняет прохождение и показывает экран завершения демо. Enter возвращает в меню.

20 ноября 2026 по просьбе автора начата разработка [прототипа комнаты 2](rooms/02-sequence.md). В текущей сцене Editor правый проход из комнаты 1 ведёт в этот прототип. Правый выход из комнаты 2 сохраняет её прохождение и остаётся заделом для комнаты 3. Головоломка «Эстафета» предложена для примерки. Согласованный ранее объём MVP указан выше.

20 ноября 2026 по просьбе автора комнаты 2–4 исключены из MVP. Для будущей реализации в сценах Unity сохранены следующие задачи.

## Управление в Editor

- WASD или стрелки — движение.
- E — взаимодействие.
- R после подбора пульта — завершить запись и вернуться к входу текущей комнаты.
- Esc — пауза. Стрелки и Enter — меню.

## Проверка и сборка

Сценарная проверка использует тестовые состояния для первого возврата, подбора пульта, исчезновения копии, завершения демо и загрузки. Ручное прохождение остаётся открытым. [Команды проверки](project-setup.md#проверка)

Готовая Windows-сборка относится к более ранней реализации. Управление в ней описано в [инструкции рядом с exe](../outputs/Golovomka-Echo-MVP/README.md).
