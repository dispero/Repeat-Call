# Golovomka: техническая основа

## Подтверждено автором 13 ноября 2026
- Название проекта: Golovomka.
- Игра для компьютеров, управление с клавиатуры.
- Новый проект, прежней реализации нет.

## Выбор при создании
- Unity 6000.6.8f1 — наиболее новая из обнаруженных установленных версий; выбрана без дополнительной загрузки Editor.
- Шаблон 2D, Universal Render Pipeline (URP). Версии пакетов фиксируются в Packages/manifest.json и packages-lock.json.
- Проект локальный, без привязки к Unity Cloud.
- В шаблоне присутствует Input System. Игровые действия и назначение клавиш пока не разработаны.
- Наличие uGUI в шаблоне не означает окончательного выбора UI для игры.

Графический пайплайн — система отрисовки: она определяет, как движок отображает изображения, свет, тени и эффекты. Для проекта выбран Universal 2D как исходная основа для спрайтов и возможного 2D-освещения. Настройки pixel-perfect, разрешение и размер пикселя предстоит определить вместе с графикой.

Точная поддержка Windows/macOS/Linux, UI, сохранения и архитектура остаются открытыми. Создание проекта не означает реализацию головоломок.
