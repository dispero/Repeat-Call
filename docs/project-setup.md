## Запуск и сборка
Сцена: Assets/Golovomka/Scenes/EchoMVP.unity. Открыть в Editor и включить Play Mode.
Windows-сборка: outputs/Golovomka-Echo-MVP/Golovomka.exe. Для запуска и передачи требуется вся папка рядом с exe. Архив не создаётся по просьбе автора. Инструкция — README.md в папке сборки.

Подготовка сцены в Editor: EchoMvpTools.Prepare(). Она создаёт сцену, настраивает импорт и включает её в сборку; не вызывать без необходимости пересоздания сцены, особенно при несохранённых изменениях.
Проверка модели: EchoMvpTools.Verify(). Выполняет значимые проверки истории и отдельного тестового сохранения.

Для управления Editor используется установленный Unity CLI. На этой машине путь: %LOCALAPPDATA%/Unity/bin/unity.exe. Проверять актуальную версию и доступные команды. Для нескольких Editor всегда указывать --project-path с полным путём Golovomka.

Примеры известных команд:
```text
unity recompile --project-path <полный путь проекта> --format json
unity command script eval --project-path <полный путь проекта> --code "return EchoMvpTools.Verify();" --format json
unity command build run --project-path <полный путь проекта> --target StandaloneWindows64 --output-path outputs/Golovomka-Echo-MVP/Golovomka.exe --confirm true --format json
unity command build status --project-path <полный путь проекта> --format json
```
Сборка асинхронна: дождаться результата build status, не считать queued успехом сборки.

## Ручная настройка столкновений мебели — 19 ноября 2026

По просьбе автора добавлен FurnitureLayout на объект EchoMVP. Он хранит 20 прямоугольников мебели участка и комнат 1–4 в сцене; начальные области совпадают с прежними программными. Меню Golovomka → Edit Furniture Hitboxes выбирает компонент. В Inspector выбрать комнату и нажать «Показать в Scene»: зелёная центральная ручка перемещает область, крайние меняют размер. Ctrl+Z отменяет изменение, Ctrl+S сохраняет сцену. Работать вне Play Mode. Gizmos и обычные инструменты движения объекта не требуются. Участок и комната 1 имеют подложку исходного фона; комнаты 2–4 пока показывают области на сетке. При построении комнаты EchoMvp берёт список из FurnitureLayout, если компонент включён; при отсутствии/отключении использует прежние области из кода. Пустой список комнаты означает отсутствие блокирующей мебели. Правила стен, дверей, плит и область ног Ивана не изменены. После правок проверять проходы в Play Mode; редактирование сохранённой сцены не обновляет уже выпущенную сборку. Prepare создаёт начальные области заново вместе со сценой, не применять его для обычной настройки.
