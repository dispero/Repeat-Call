# Техническая основа

Unity 6000.6.8f1, Universal 2D/URP, Input System, uGUI, Windows x64. Сверяй версию и пакеты с `ProjectSettings/ProjectVersion.txt` и `Packages/manifest.json`.

## Сцены и переходы

`Assets/Golovomka/Scenes/Game.unity` в Play Mode через `EchoMvp` загружает `PoliceStation.unity` и `Laboratory.unity` и переключает их корни. Все три входят в сборку. Точки появления задают `PoliceStationLayout` и `LaboratoryRoom`. Вход в подвал начинает запись и сохраняет первую точку продолжения. Отсутствующие сцены и обязательные ссылки дают ошибки Console. `EchoMvpTools.Prepare()` пересоздаёт основную сцену и настройки. При обычных правках редактируй существующие сцены.

`LaboratoryRoom` на корне комнаты:

- `Room Number` — уникальный номер записи (1–5). В финале запись начинается при входе после тира и после каждого возврата.
- `Entrance` — вход и точка возврата по R. У перехода может быть отдельная точка `Arrival`.
- `Camera Area` — границы по триггеру `BoxCollider2D`. Без него берутся `Camera Size` и центр объекта. `Preview Width` добавляет запас справа.
- `Passages` — E у `Marker` в пределах `Interaction Radius` либо пересечение порога `Crossing Door` по `Cross To Right`. `Crossing Offset` сдвигает порог от середины двери. Положительное значение ставит порог по направлению прохода, отрицательное — перед дверью. `Destination` выбирает комнату, участок, сообщение или завершение. Для комнаты назначь `Target Room`. `Sets Return Point` требует пульт и запоминает вход новой комнаты, сохраняя текущую позицию Ивана. Настраивай переходы в обе стороны.

## Графика и камера

- Ручной кадр в `Game`: отключи `Auto Fit Room` у `EchoMvp`, настрой `Main Camera`. Участок виден целиком. В подвале `EchoMvp.Viewport.cs` держит высоту и плавно следует по X за пределами центральной зоны (0,4 ширины, сглаживание 0,22 с). Переходы непрерывны, R мгновенно переносит камеру. По уточнению автора от 24 ноября 2026 в комнатах 1–4 верх и низ кадра совпадают с наружными краями стен.
- `Ivan.prefab` в `Assets/Golovomka/Characters/Prefabs`. Масштаб — Transform, скорость — `Move Speed`, в комнате 1 масштаб Ивана и копии ×0,65. В Editor виден `IvanIdlePreview`, в игре — кадры `CharacterWalk`. Атласы Ивана лежат в `Assets/Golovomka/Characters/Sprites`. `IvanUnifiedWalk` содержит 16 кадров для основных направлений и четыре статичные диагональные позы. `IvanPistolPoses` содержит четыре стойки с пистолетом, `IvanPistolWalk` — двенадцать кадров ходьбы с ним.
- PixelPerfectCamera отключён (временные 16 PPU, 480×270). Point, сетка движения 1/16. HUD 1280×720, подписи мира в пределах viewport 0,14–0,82 по вертикали.
- Modern Interiors Free v2.2 (LimeZu) предназначен для некоммерческого использования. [Текст лицензии](references/LICENSE-LimeZu.txt).

## Столкновения

Коллизии соответствуют видимым стенам, мебели и дверям. Хитбокс ног 0,44 × 0,28 проверяется вдоль каждого шага. Пол и триггеры проходимы. Для контура участка предусмотрены отдельные коллайдеры. В лаборатории слои «Стены» и «Задняя стена» используют `TilemapCollider2D`. Мебель настраивается через Edit Collider. У `SlidingDoor` один подвижный `BoxCollider2D`: триггер при открытой двери и пока Иван в проёме, препятствие после закрытия и выхода. Маска проёма отвечает за вид. После правок проверь проходы в `Game`.

23 ноября 2026 по просьбе автора проверены участок и комнаты 1–5. Границы напольных предметов учитывают боковой зазор для силуэта Ивана. Проверены подходы к мебели, тележкам, стойкам кнопок, оборудованию тира и контейнерам финала. Дополнительные границы блока и контейнеров финала находятся в `Player Furniture Clearance` на слое `Ignore Raycast`. Ходьба Ивана учитывает эти коллайдеры, а противники и выстрелы в финале используют основные границы укрытий.

У створок подвала есть отдельный боковой упор `Door Approach` на слое `Ignore Raycast`. При открытии он становится триггером вместе с проёмом. При закрытии коллайдеры дают Ивану выйти за край створок. Для перехода между комнатами используется основной коллайдер проёма.

После уточнения автора от 23 ноября 2026 открытие и закрытие створок занимают по 0,45 с от одного крайнего положения до другого. При переходе вперёд анимация сохраняет текущее положение створок.

`SlidingDoor` один раз воспроизводит `DoorOpen` в начале открытия и `DoorClose` в начале закрытия. При мгновенной смене положения звучит соответствующий клип. Если створки меняют направление на ходу, начинается новый звук.

## Сохранение

`EchoHistory` пишет `echoes-mvp-v3.json` в `Application.persistentDataPath` и сохраняет `.bak` при замене. Сохраняются завершённые записи и события, цикл, подбор пульта и комната возврата. До спуска продолжение начинается у телефона. После спуска оно начинается у входа в последнюю сохранённую комнату. Для старого сохранения с пультом или записью без точки возврата используется вход комнаты 1.

При миграции v3 комнаты 3 и 4 становятся 4 и 5 с переносом точки возврата и сдвигом кадров на ширину вставленной комнаты. Для форматов 3–5 сохраняются точка возврата и последняя запись по остальным комнатам, старые записи тира сбрасываются из-за переноса мишеней. `room = 0` означает общий трек. Новая локальная запись удаляет весь старый общий трек, если в нём есть кадры её комнаты.

Формат сохранения 8 поддерживает выстрелы и завершение финала. Формат 7 добавил состояние пистолета в кадрах. При загрузке формата 6 копии в тире по-прежнему держат пистолет на протяжении всей записи.

Новые записи выстрелов включают смещение от исходной точки до ствола. Старые записи без смещения используют сохранённую точку. При выстреле вверх применяется центральная ось персонажа вместо прежнего смещения вбок.

## Проверка

Unity CLI — `%LOCALAPPDATA%/Unity/bin/unity.exe`. Перед запуском сверь Editor. Ниже `<проект>` — полный путь. Папка Windows-сборки указана в [README](../README.md).

```text
unity recompile --project-path <проект> --format json
unity command script eval --project-path <проект> --code "return EchoMvpTools.Verify();" --format json
unity command build run --project-path <проект> --target StandaloneWindows64 --output-path Builds/Golovomka-Windows-x64/Golovomka.exe --confirm true --format json
unity command build status --project-path <проект> --format json
```

Сборка асинхронна, проверяй результат через `build status`. `EchoMvpTools.Verify()` проверяет интерполяцию, конец записи, лимиты, сохранение и резервную копию. В отдельном Play Mode `EchoIntroductionVerification.VerifyPlay()` подставляет состояния для переходов, возвратов, кнопок, тира и миграции. Сохранение проверки — `work/intro-verification-save.json`.
