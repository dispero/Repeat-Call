# Комната 3 — цветные кнопки

## Статус

ВАРИАНТ автора от 21 ноября 2026. Между «Эстафетой» и испытанием с двумя копиями появляется комната с тремя цветными кнопками и одной копией.

## Устройство и решение

Кнопки 1, 2 и 3 разнесены по комнате. Кнопка 2 находится между 1 и 3. У каждой свой цвет. На стене видна вся последовательность. Кнопки загораются по одному шагу в заданном порядке. Пока кнопка горит, её нужно успеть нажать. Скобки ниже обозначают долю одного участника в предполагаемом решении. Второй выполняет шаги без скобок.

| Вариант | Полная последовательность | Участник со скобками | Второй участник |
|---|---|---|---|
| А | `(1) → 3 → (2) → 3 → (2) → 2 → (1)` | 1 → 2 → 2 → 1 | 3 → 3 → 2 |
| Б | `(1) → 3 → (2) → 3 → (2) → (2) → 1` | 1 → 2 → 2 → 2 | 3 → 3 → 1 |

Для первой примерки предлагается А. В начале участники занимают противоположные стороны комнаты. Затем оба подходят к центральной кнопке и нажимают её по очереди, а последний шаг возвращает первого участника к кнопке 1. В варианте Б один участник трижды нажимает 2, пока другой после второго нажатия 3 перебегает через комнату к 1.

## Вариант для проверки

- Дать каждому шагу своё окно по расписанию. Два соседних шага на кнопке 2 требуют двух отдельных нажатий. Подсветка должна показывать начало второго окна.
- Подобрать интервалы по фактическому времени бега. Даже при самом раннем нажатии 1 игрок в одиночку должен опаздывать к концу первого окна для 3. При этом оба участника должны успевать на свои шаги с запасом.
- Во время подготовки записи подсветка проходит всю последовательность даже при пропущенных шагах. Так можно записать только свою долю. После R подсветка и воспроизведение стартуют с одного момента. Пропуск делает попытку неуспешной, дверь открывается после всех верных нажатий за одну попытку.
- Для головоломки нужно записывать и воспроизводить отдельные нажатия кнопок с их временем. Порядок и отметки текущей попытки сбрасываются при возврате. Способ сохранить удачную запись при повторе и правила для лишних нажатий предстоит выбрать.

Открыты точные интервалы, расстояния, цвета и момент первого сигнала. В проверке пройти обе роли с одной копией, попробовать пройти в одиночку и убедиться, что после промаха можно повторить испытание.
