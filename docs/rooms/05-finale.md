**СОГЛАСОВАНО 21 ноября 2026 по запросу автора.** После тира Иван и одна его копия сражаются с тремя бандитами. Точный формат боя открыт. Автор предпочитает свободный бой, тактический остаётся вариантом.

В текущих исходниках за тиром описан отсек 5. Инструкция к `Builds/Golovomka-Windows-x64` описывает финал с удержанием панели копией, прицеливанием мышью, перезаписью через Shift+R и эпилогом. Совпадение сборки с исходниками не проверено запуском. Записка для отсека отложена 22 ноября по уточнению автора.

В отсеке 5 работает Q и ходьба с пистолетом. При проходе из тира Иван сохраняет текущее состояние оружия.
