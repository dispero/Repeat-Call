# Golovomka

Unity 2D top-down pixel-art головоломка для компьютеров с управлением с клавиатуры.

Откройте эту папку в Unity Hub с Unity 6000.6.8f1. Начните чтение с [AGENTS.md](AGENTS.md), [технической основы](docs/project-setup.md) и [контекста игры](docs/game-context.md).

Спецификации находятся в [docs/puzzles](docs/puzzles/01-access-protocol.md). Первое испытание согласовано на уровне основы; второе требует доработки, третье — бумажного прототипа. Игровая реализация этих испытаний ещё не создана.
