# Golovomka

Unity 2D top-down pixel-art для Windows. Полицейский Иван проходит лабораторию с помощью копий своих предыдущих действий.

- Unity 6000.6.8f1: открыть `Assets/Golovomka/Scenes/Game.unity` и включить Play Mode.
- Windows x64: запустить `Builds/Golovomka-Windows-x64/Golovomka.exe`. Для передачи скопировать всю папку.
- [Правила проекта и указатель документов](AGENTS.md) · [Маршрут и управление](docs/mvp-echoes.md).

Графика участка и Ивана — собственная с AI, окружение подвала — Modern Interiors Free v2.2 (LimeZu). Версия предназначена для некоммерческого тестирования.
